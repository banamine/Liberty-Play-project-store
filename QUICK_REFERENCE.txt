TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────
Problem: Channels don't load
  → Check Vercel env vars are set and scoped to all 3 (Production, Preview, Dev)
  → Check Vercel Runtime Logs for [ArchiveM3U] or error messages
  → Visit Stream Vault health endpoint to verify it's running

Problem: Some channels fail to load
  → This is normal — Archive.org may be temporarily down
  → Other channels will load successfully
  → Check Vercel logs for which URLs are failing

Problem: Video plays then stops ("Playback Interrupted")
  → Clear browser cache (Ctrl+Shift+Delete)
  → Try a different channel
  → Check browser console for HLS errors

Problem: Deployment still pending after 10 minutes
  → Refresh Vercel Deployments page
  → Check if there are build errors in Runtime Logs
  → Look for type errors or lint violations
